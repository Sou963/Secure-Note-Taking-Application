REST API + basic frontend with JWT authentication and role-based access control (User / Admin).

## Stack

- **Backend**: Node.js, Express
- **Database**: MongoDB + Mongoose (MongoDB Atlas on production)
- **Auth**: JWT + bcryptjs
- **Deploy**: Vercel (API + frontend)
